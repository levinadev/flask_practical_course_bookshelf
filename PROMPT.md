# Задача: фронтенд для Flask-приложения "Книжная полка"

Ты опытный фронтенд-разработчик. Создай HTML-шаблоны Jinja и CSS для моего Flask-приложения "Книжная полка", читательского дневника. Бэкенд уже написан: **не меняй Python-файлы**, создай только файлы, перечисленные ниже.

## Файлы, которые нужно создать

```
bookshelf/templates/base.html
bookshelf/templates/auth/register.html
bookshelf/templates/auth/login.html
bookshelf/templates/books/index.html
bookshelf/templates/books/form.html
bookshelf/templates/books/stats.html
bookshelf/templates/errors/error.html
bookshelf/static/style.css
```

## Общие правила

- Все страницы наследуют `base.html` через `{% extends "base.html" %}` и заполняют блоки `title` и `content`.
- Все ссылки строй только через `url_for(...)`, CSS подключай через `url_for('static', filename='style.css')`.
- Не используй фильтр `|safe` и не отключай автоэкранирование.
- Никаких внешних библиотек и CDN: только свой CSS, без JavaScript (кроме `confirm()` при удалении книги).
- Дизайн: светлый, тёплый, минималистичный, "книжный"; карточки со скруглёнными углами; страницы должны хорошо выглядеть на телефоне.
- Язык интерфейса русский.

## base.html

- `<title>`: `{% block title %}{% endblock %}, Книжная полка`.
- Шапка с логотипом "Книжная полка" (ссылка на `url_for('index')`).
- Меню: если `g.user` есть, ссылки "Мои книги" (`url_for('index')`), "Добавить" (`url_for('books.create')`), "Статистика" (`url_for('books.stats')`), имя пользователя `g.user['username']` и "Выйти" (`url_for('auth.logout')`); иначе, "Войти" (`url_for('auth.login')`) и "Регистрация" (`url_for('auth.register')`).
- Перед блоком `content` выведи flash-сообщения: `get_flashed_messages(with_categories=true)`; категории, `success` и `error`, оформи их разными цветами.

## auth/register.html и auth/login.html

- Форма `method="post"` с полями `username` и `password` (у пароля `type="password"`).
- Поле `username` после неудачной отправки сохраняет введённое значение: `request.form['username']`.
- Ссылка на соседнюю страницу: со входа, на регистрацию, с регистрации, на вход.

## books/index.html

Переменные: `books` (список; у книги есть `id`, `title`, `author`, `status`, `rating`, число 1-5 или `None`, `note`), `statuses` (словарь "код статуса и название", например `want` и "Хочу прочитать"), `current_status` (выбранный фильтр или `None`).

- Заголовок "Мои книги" и кнопка "Добавить книгу" (`url_for('books.create')`).
- Фильтры-"таблетки": "Все" (`url_for('index')`) и по одному для каждого статуса (`url_for('index', status=key)`); активный фильтр выделен.
- Карточки книг: значок статуса (`statuses[book['status']]`), название, автор, оценка звёздочками (если есть), заметка (если есть), ссылка "Изменить" (`url_for('books.update', book_id=book['id'])`) и кнопка "Удалить", отдельная форма `method="post"` на `url_for('books.delete', book_id=book['id'])` с подтверждением.
- Если книг нет, дружелюбная заглушка с кнопкой "Добавить книгу".

## books/form.html

Переменные: `book` (книга при редактировании или `None` при создании), `statuses`.

- Заголовок "Новая книга" или "Редактирование".
- Форма `method="post"` с полями: `title`, `author` (текстовые), `status` (выпадающий список из `statuses`), `rating` (список: "Без оценки" с пустым значением и варианты 1-5), `note` (textarea).
- Значение каждого поля: сначала `request.form[...]` (если форму вернули с ошибкой), иначе значение из `book`, иначе пусто (статус по умолчанию, `want`).
- Кнопка "Сохранить" и ссылка "Отмена" на `url_for('index')`.

## books/stats.html

Переменные: `total`, `counts` (словарь "код статуса и количество"), `statuses`, `avg_rating` (число или `None`).

- Карточки-счётчики: всего книг, по каждому статусу, средняя оценка (если `None`, показать "-").

## errors/error.html

Переменные: `code` (например, 404), `message`. Крупно код, ниже сообщение и кнопка "На главную".

## style.css

Единый стиль для всех страниц: шапка, контейнер по центру (до ~960px), карточки, кнопки, поля форм, flash-сообщения, фильтры, сетка карточек книг (адаптивная), значки статусов разными цветами.

Когда закончишь, перечисли созданные файлы и коротко опиши, что в каждом.
